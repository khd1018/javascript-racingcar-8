# javascript-racingcar-precourse

## 기능 목록

- 자동차를 전진시킬 수 있다.

  - 무작위 값이 4 이상인지 확인할 수 있다.
  - 사용자의 위치를 업데이트할 수 있다. ( 전진 시 원래 자동차 위치에 1을 더한다 )

- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알 수 있다.

  - 각 자동차들이 이동한 거리를 비교할 수 있다.
  - 자동차들이 이동한 거리가 같은지 알 수 있다.
  - 가장 멀리 이동한 자동차를 알 수 있다.
  - 가장 멀리 이동한 자동차들(최종 우승자)을 찾을 수 있다.

- 사용자가 잘못된 값을 입력할 경우 Error를 발생시킨 후 애플리케이션을 종료시킬 수 있다.

## 입출력 요구사항 및 주의 사항

### 입력

1. 경주할 자동차 이름

- 이름은 쉼표를 기준으로 구분하여 입력해야 한다.
- 자동차의 이름은 5자 이하만 가능하다.
- 자동차 이름을 2대 이상 입력해야 한다.
- 자동차 이름을 100대 이상 입력할 수 없다.

2. 시도 횟수

- 시도 횟수는 양수를 입력해야 한다.
- 시도 횟수는 100번 이상을 입력할 수 없다.

### 출력

- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지를 출력한다.
- 각 자동차들의 이름과 차수별 실행 결과를 출력한다.
- 최종 우승자의 이름을 출력한다. 한명 이상인 경우 쉼표(,)로 구분해서 출력한다.
